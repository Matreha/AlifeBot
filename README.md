# Бот "ЖИВ?"

Бот проверяет активность пользователей по расписанию и пересылает их ответы владельцу.

## Расписание
- Суббота в 20:00 МСК
- Воскресенье в 8:00 МСК  
- Воскресенье в 20:00 МСК

## Переменные окружения
- `BOT_TOKEN` — токен бота от @BotFather
- `OWNER_CHAT_ID` — ваш chat_id (куда пересылать ответы)

## Команды для владельца
- `/test` — тестовая рассылка "ЖИВ?" всем пользователям
- `/users` — показать список пользователей
- `/start` — показать панель управления с кнопками

## Запуск
```bash
pip install -r requirements.txt
python bot.py
